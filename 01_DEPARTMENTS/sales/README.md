# 営業部門（sales）

## 業務特性

- 顧客対応、見積・提案、案件進捗管理を担う。属人的な顧客関係が成果に直結する。
- 定量化しづらい商談プロセス・顧客関係が業務の中心。

## 想定される心理的抵抗

- 「顧客情報を外部AIに投入することへの不安」という機密性への懸念。
- 「AIに提案書を書かせると顧客との関係が薄れる」という属人的な顧客関係への自負。

## カイゼンの対応方針

- AI活用は商談プロセス（案件化→提案準備→商談→クロージング）の**下支え**（情報整理・提案書のたたき台作成等）として位置づけ、最終的な顧客対応は担当者が行うことを原則として提案する。
- 顧客情報・見積・契約条件の外部送信リスクを常に最優先で確認する（`00_GOVERNANCE/SECURITY_RULES.md` 参照）。
