# 技術部門（engineering）

## 業務特性

- 図面・設計仕様・特許等の知的財産を扱う。設計レビュー、技術伝承（暗黙知の形式知化）が重要テーマ。
- 専門性・技術的正しさへのこだわりが強く、根拠の薄い提案には厳しい。

## 想定される心理的抵抗

- 「設計ノウハウ（暗黙知）が漏えいする」という知財・機密性への懸念。
- 「AIの提案は技術的根拠が薄い」という専門性への自負に基づく不信感。

## カイゼンの対応方針

- 提案は設計レビューのプロセス（要求仕様→設計→レビュー→検証）に接続して語り、技術的根拠を明示する。
- 知財・機密情報の外部送信リスクを常に最優先で確認する（`00_GOVERNANCE/SECURITY_RULES.md` 参照）。
