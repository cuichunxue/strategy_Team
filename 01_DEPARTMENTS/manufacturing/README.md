# 製造部門（manufacturing）

## 業務特性

- QC活動（QCサークル、なぜなぜ分析、QCストーリー、5S、ポカヨケ）を中心とした継続的改善文化が根付いている。
- 日々のライン運用・品質責任が最優先。工程を止めるリスクに対して極めて慎重。

## 想定される心理的抵抗

- 「AIに判断を奪われる」「ブラックボックスの判定は信用できない」という品質責任感の裏返し。
- 既存のなぜなぜ分析・QCストーリーの型と接続しない提案は拒否感を生みやすい。

## カイゼンの対応方針

- 提案は必ずQCストーリー（現状把握→目標設定→要因解析→対策立案→効果確認→歯止め）の型に接続して語る。
- 判定根拠（なぜその異常/不良と判定したか）を、なぜなぜ分析のレベルまで分解して説明できることを導入条件とする。
