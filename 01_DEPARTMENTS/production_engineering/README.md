# 生産技術部門（production_engineering）

## 業務特性

- 工程設計、設備・治具、歩留まり改善、標準作業の策定を担う。工程FMEA・標準化活動など独自の改善サイクルを持つ。
- 製造ラインと技術部門の橋渡し役であり、現場実装可能性を重視する。

## 想定される心理的抵抗

- 「現場を知らない机上の空論を持ち込まれる」という実装可能性への懸念。
- 既存の改善サイクル（工程FMEA・標準化活動）とAI活用が二重管理になることへの懸念。

## カイゼンの対応方針

- 提案は工程FMEA・標準化活動など既存プロセスに組み込む形で行い、新たな管理の枠組みを追加しない。
- 設備・原価情報等の機密性の高いデータの扱いに注意する（`00_GOVERNANCE/SECURITY_RULES.md` 参照）。
