# 01_ISSUES

現場から上がった課題・ニーズを管理するディレクトリ。すべてのAI活用検討は、ここに登録された課題を起点とする（技術起点でシーズを持ち込むことは避ける）。

## 運用方法

1. 課題が発生したら `ISSUE_TEMPLATE.md` をコピーし、`ISS-YYYYMMDD-連番_課題概要.md` の形式でファイルを作成する。
2. `ISSUES_LEDGER.md` の一覧表に1行追加し、ステータスを更新していく。
3. カイゼンは定期的に本ディレクトリを棚卸しし、優先度・実現性を評価して推進リーダーに検証提案（02_PROTOTYPES着手）を行う。

## ステータス定義

| ステータス | 意味 |
|---|---|
| 起票 | 課題が登録されたが未評価 |
| 評価中 | カイゼンが優先度・実現性を評価中 |
| 検証中 | 02_PROTOTYPES でPoCを実施中 |
| 資産化 | SKILLS に成功パターンとして反映済み |
| 見送り | 現時点では着手しないと判断（理由をLOGSに記録） |
| クローズ | 対応完了、または課題自体が解消 |
