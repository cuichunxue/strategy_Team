# 00_STRATEGY

全社改革ロードマップ、各部門のROI試算、経営提言書を格納するディレクトリ。ジョブズが部門横断で行う診断・ソリューション実証の成果を、経営レベルの意思決定材料に集約する場所。

## ファイル構成

- `ROADMAP.md` — 全社改革ロードマップ。四半期・半期単位での改革テーマと部門別の優先順位。
- `ROI_LEDGER.md` — 各部門のROI試算台帳。`01_DIAGNOSTICS` での暫定試算から `02_SOLUTIONS` での実績値までを一元管理する。
- `PROPOSALS/` — 全社インパクトの大きい施策・複数部門にまたがる経営提言書。`PROPOSALS/EXECUTIVE_PROPOSAL_TEMPLATE.md` を使用する。

## 位置づけ

`01_DIAGNOSTICS`（診断）→ `02_SOLUTIONS`（実証）→ `SKILLS`（資産化）という現場に近いレイヤーの活動を、`00_STRATEGY` が経営視点で統合し、改革オーナーの意思決定に直結させる。ROI試算のない施策、ロードマップ上の位置づけが不明な施策は、経営提言として提出しない。
