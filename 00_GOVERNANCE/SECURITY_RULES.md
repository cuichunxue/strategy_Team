# セキュリティルール（MUST）

本ルールは製造業AI活用における最低限の遵守事項である。例外を設ける場合は必ず推進リーダーの承認を得て `LOGS/` に記録する。

## 1. データ取り扱い

1. 図面、金型・工程情報、原価、歩留まり、顧客情報、個人情報を含むデータを、承認されていない外部AIサービス・外部APIに送信してはならない。
2. 02_PROTOTYPES で使用するデータは、原則としてサンプル化・匿名化・マスキングされたものを用いる。実データを使う検証は、推進リーダーの事前承認と利用目的・保存期間・廃棄方法の明記を必須とする。
3. 検証で使用したデータ・生成物のうち、社外に公開してはならないものは `.gitignore` 等で管理し、リポジトリに機密情報をコミットしない。

## 2. AIモデル・ツールの利用

4. 本番の製造工程・品質判定に、検証（PoC）を経ていないAIモデル・プロンプトを適用してはならない。
5. AIの判定・提案を人手の最終確認なしに自動で工程に反映する運用（フルオートメーション）は、段階的検証で十分な信頼性が確認されるまで導入しない。
6. 外部AIサービスを利用する場合は、利用規約上のデータ学習利用有無・データ保持期間を確認し、`00_GOVERNANCE` に記録した上で利用する。

## 3. アクセス・権限

7. 本リポジトリおよび関連ツールへのアクセス権限は、必要最小限（Need to Know）の原則で付与する。
8. 認証情報・APIキー・トークン類はリポジトリに含めない。環境変数または社内シークレット管理の仕組みを用いる。

## 4. 変更管理

9. `00_GOVERNANCE` 配下のルール変更は、推進リーダーとカイゼンの双方合意を必須とし、変更履歴を残す。
10. セキュリティ上の懸念（インシデント、ルール違反の疑い等）を検知した場合、カイゼンは検証・提案活動より報告を優先する。
