# 00_GOVERNANCE

本ディレクトリは、AI活用戦略チームが守るべき「セキュリティルール」と「セキュリティガイドライン」を格納する。すべてのプロトタイピング（02_PROTOTYPES）・スキル資産化（SKILLS）は、本ディレクトリの内容に反しないことを前提とする。

## ファイル構成

- `SECURITY_RULES.md` — 遵守必須のルール（MUST）。違反時は活動を停止する。
- `SECURITY_GUIDELINE.md` — 推奨される実務指針（SHOULD）。状況に応じた判断の目安。

## 位置づけ

- ルール・ガイドラインは推進リーダーとカイゼンの合意のもとで改訂する。
- 現場から見て「何を守れば安心して協力できるか」が一目でわかることを目的とする。心理的抵抗の多くは「データがどう使われるか分からない不安」に起因するため、本ディレクトリは技術文書であると同時に**現場との信頼構築の文書**でもある。
