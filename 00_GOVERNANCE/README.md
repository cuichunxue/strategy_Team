# 00_GOVERNANCE

本ディレクトリは、全社（製造・技術・生産技術・営業）で共通して守るべき「全社AI利用ガイドライン」と「セキュリティルール」を格納する。すべての部門別課題対応（01_DEPARTMENTS）・プロトタイピング（02_PROTOTYPES）・スキル資産化（SKILLS）は、本ディレクトリの内容に反しないことを前提とする。

## ファイル構成

- `AI_USAGE_GUIDELINES.md` — 全社AI利用ガイドライン。部門を問わず、AIをどう使い・どう使わないかの共通指針（推奨事項含む、SHOULD）。
- `SECURITY_RULES.md` — 遵守必須のセキュリティルール（MUST）。違反時は活動を停止する。

## 位置づけ

- ガイドライン・ルールは推進リーダーとカイゼンの合意のもとで改訂する。
- 各部門から見て「何を守れば安心して協力できるか」が一目でわかることを目的とする。製造の心理的抵抗、技術の知財懸念、営業の顧客情報懸念など、部門ごとに不安の質は異なるため、本ディレクトリは技術文書であると同時に**部門横断の信頼構築の文書**でもある。
