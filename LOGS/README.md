# LOGS

改革オーナーとジョブズ（AI Chief Visionary Officer）の戦略対話・意思決定を記録するディレクトリ。後から「なぜその判断をしたか」「試算はどこまで当たったか」を追跡できることを目的とする。

## 運用方法

- 重要な意思決定（診断の優先順位付け、ソリューション着手・中止、SKILLSへの資産化判断、ルール改訂、ROI試算と実績の乖離の総括等）が発生するたびに `YYYY-MM-DD_件名.md` を作成する。
- テンプレートは `STRATEGIC_LOG_TEMPLATE.md` を参照。
- 「採用した選択肢」だけでなく「検討したが採用しなかった選択肢とその理由」「試算値と実績値の乖離とその要因」も残す。
