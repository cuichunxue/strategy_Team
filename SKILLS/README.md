# SKILLS

02_PROTOTYPES での検証を経て「効果確認・歯止め」まで到達した成功パターンを、再利用可能なモジュールとして資産化するディレクトリ。属人化を防ぎ、他ライン・他工場への水平展開を可能にすることが目的。

## 構成ルール

`SKILLS/<スキル名>/` 配下に以下を格納する。

- `README.md` — 用途、適用条件、限界・注意点、由来（元になった課題ID・PoC）
- 実装（コード／プロンプト／テンプレート等）

## 命名例

- `qc_story_audit/` — QCストーリー（現状把握〜歯止め）の記述をAIが監査し、論理の飛躍や要因解析の浅さを指摘するスキル
- `reliability_analysis/` — 故障データ・稼働データから信頼性解析（ワイブル分析等）を支援するスキル
- `naze_naze_assist/` — なぜなぜ分析の深掘り支援（「なぜ」の連鎖が真因に到達しているかをチェック）

上記はディレクトリ構成の例であり、実際のスキルは検証結果に基づき随時追加する。
