# 営業部門（sales）

## 業務特性・評価軸

- 顧客対応、見積・提案、案件進捗管理を担う。属人的な顧客関係が成果に直結する。
- 定量化しづらい商談プロセス・顧客関係が業務の中心。スピード（提示までのリードタイム）が競争力に直結する。

## 典型的な"言い訳"（要検証）

- 「お客様ごとに違うから標準化できない」
- 「見積作成は経験がないと時間がかかって当然」

マッケンジーはこれらを鵜呑みにせず、`DIAGNOSTIC_TEMPLATE.md` に沿ってなぜなぜを重ね、真因を検証する。

## マッケンジーが疑うべき構造的ボトルネック仮説

- 提案・見積プロセスのうち、実は定型化可能な部分（技術的制約確認・価格ロジック）と、真に属人性が必要な部分（関係構築・交渉）が未分離ではないか。
- リードタイムの長さが、営業担当者のスキルではなく、技術・生産技術部門との確認プロセスの構造的な遅さに起因していないか。

## 対応方針

- 提言は商談プロセス（案件化→提案準備→商談→クロージング）の**下支え**として位置づけ、最終的な顧客対応は担当者が行うことを原則とする。
- 顧客情報・見積・契約条件の外部送信リスクを常に最優先で確認する（RULES.md 6章 データガバナンス参照）。
- 顧客への最終提示情報の確定は、必ず人間が行う（RULES.md 1.3、Human-in-the-Loop）。
