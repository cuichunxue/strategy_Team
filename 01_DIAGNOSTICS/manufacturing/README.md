# 製造部門（manufacturing）

## 業務特性・評価軸

- QC活動（QCサークル、なぜなぜ分析、QCストーリー、5S、ポカヨケ）を中心とした継続的改善文化が根付いている。
- 日々のライン運用・品質責任が最優先。工程を止めるリスクに対して極めて慎重。品質責任感の強さが、変化への慎重姿勢の背景にある。

## 典型的な"言い訳"（要検証）

- 「人手を増やさないと検査が追いつかない」
- 「このラインは特殊で自動化は無理」

ジョブズはこれらを鵜呑みにせず、`DIAGNOSTIC_TEMPLATE.md` に沿ってなぜなぜを重ね、真因を検証する。

## ジョブズが疑うべき構造的ボトルネック仮説

- 検査基準・工程設計自体が過剰品質、あるいは属人化していないか。
- 「特殊」の中身が、実は標準化・自動化可能な部分と、本当に人の勘・コツが必要な部分に分離できていないか。

## 対応方針

- 提言はQCストーリー（現状把握→目標設定→要因解析→対策立案→効果確認→歯止め）の型に接続しつつ、要因解析の深さが不十分な箇所には第一原理で切り込む。
- ソリューションの判定根拠（なぜその異常/不良と判定したか）は、なぜなぜ分析のレベルまで分解して説明できることを実証の必須条件とする。
- 品質保証・合否判定に関わる最終判断は、必ず人間が行う（RULES.md 1.3、Human-in-the-Loop）。
