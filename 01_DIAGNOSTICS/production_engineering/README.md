# 生産技術部門（production_engineering）

## 業務特性・評価軸

- 工程設計、設備・治具、歩留まり改善、標準作業の策定を担う。工程FMEA・標準化活動など独自の改善サイクルを持つ。
- 製造ラインと技術部門の橋渡し役であり、現場実装可能性を重視する。

## 典型的な"言い訳"（要検証）

- 「この工程はうちの会社特有で仕方ない」
- 「歩留まりのばらつきは職人の勘の問題」

マッケンジーはこれらを鵜呑みにせず、`DIAGNOSTIC_TEMPLATE.md` に沿ってなぜなぜを重ね、真因を検証する。

## マッケンジーが疑うべき構造的ボトルネック仮説

- 特殊性の主張の裏に、単なる工程設計の負債（過去の場当たり対応の蓄積）が隠れていないか。
- 「職人の勘」とされる判断が、実際には測定可能な条件（温度・圧力・タイミング等）に還元できないか。

## 対応方針

- 提言は工程FMEA・標準化活動など既存プロセスに組み込む形で行い、新たな管理の枠組みを追加しない。
- 設備・原価情報等の機密性の高いデータの扱いに注意する（RULES.md 6章 データガバナンス参照）。
- 設備停止・稼働継続の判断は、必ず人間が行う（RULES.md 1.3、Human-in-the-Loop）。
