# 潜在ニーズ診断マトリクス（LATENT_NEEDS_DIAGNOSIS）

- **作成者**: ジョブズ（AI Chief Visionary Officer）
- **作成日**: 2026-08-10
- **目的**: 各部門が語る「表面上の悩み」を第一原理思考（RULES.md 2章）で分解し、その裏にある「恐怖」「構造的ボトルネック」「構造的損失（structural losses）」を特定した上で、真に解くべき潜在ニーズを言語化する。単なるAIツール操作研修ではなく、教育・ナレッジデリバリー戦略（`02_SOLUTIONS/action_learning_program/`）の設計根拠として使用する。

## 診断の考え方

部門が語る不満・言い訳は「嘘」ではないが「本質」でもない。第一原理で分解すると、その裏には概ね以下の3層が隠れている。

1. **恐怖（Fear）**: 変化によって自分の存在価値・専門性・責任範囲が脅かされることへの防衛反応
2. **構造的ボトルネック（Bottleneck）**: 個人の能力や意欲ではなく、業務プロセス・データ・組織構造に起因する制約
3. **構造的損失（Structural Losses）**: ボトルネックが放置されることで発生している、定量化可能な工数・機会・品質の損失

表面上の悩みは、この3層が混ざり合った状態で発話される。これを分解しないまま「AI研修」を実施しても、恐怖は解消されず、ボトルネックも構造的損失も残る。

## 対比マトリクス

### 製造

| 項目 | 内容 |
|---|---|
| 表面上の悩み | 「人手を増やさないと検査が追いつかない」／「AIに判断を任せると品質が保てない」 |
| 恐怖（Fear） | 見逃しによる重大不良流出を自分の判断ミスとして背負うことへの恐怖／自分の勘・コツが「不要なもの」と判定されることへの存在価値の喪失恐怖 |
| 構造的ボトルネック | 検査基準・合否判定ロジックが個人の経験に属人化しており、言語化・共有されていない／なぜなぜ分析が「対策」止まりで「歯止め」の標準化まで到達しない |
| 構造的損失（定量化余地） | 検査工数の膨張、判定基準のばらつきによる手戻り・クレーム対応コスト、ベテラン退職によるノウハウの消失リスク |
| 真の潜在ニーズ | 「AIに判断を奪われたくない」のではなく、**「自分の勘・コツが正しく評価され、後進に継承される仕組みが欲しい」「見逃しのリスクを自分一人で背負いたくない」** |

### 技術（開発・設計）

| 項目 | 内容 |
|---|---|
| 表面上の悩み | 「設計には経験が必要で標準化できない」／「AIの提案は技術的根拠が薄い」 |
| 恐怖（Fear） | 過去の設計判断の妥当性を外部（AI）から否定されることへの専門性への恐怖／暗黙知を形式知化すると自分の付加価値・キャリア上の希少性が下がることへの恐怖 |
| 構造的ボトルネック | 過去の設計判断理由（なぜこの仕様を選び、なぜ別案を却下したか）が記録されておらず検索不能／設計レビューが「相談できるベテランが空いているか」に依存 |
| 構造的損失（定量化余地） | 過去に検討済みの案を再検討する二重工数、ベテランへの相談待ち行列によるリードタイム延伸 |
| 真の潜在ニーズ | 「経験を否定されたくない」のではなく、**「過去の判断根拠を掘り起こす手間から解放されたい」「相談待ちのボトルネックを解消し、もっと難しい設計判断に時間を使いたい」** |

### 生産技術

| 項目 | 内容 |
|---|---|
| 表面上の悩み | 「この工程はうちの会社特有で仕方ない」／「歩留まりのばらつきは職人の勘の問題」 |
| 恐怖（Fear） | 工程の特殊性を否定されると、これまでの現場対応の正当性・自部門の専門性が否定される恐怖／設備停止判断の責任をAIに委ねることへの安全責任への恐怖 |
| 構造的ボトルネック | 過去の場当たり対応の蓄積（工程設計の負債）が可視化されておらず、標準化の起点がない／FMEAが作成後に更新されず形骸化している |
| 構造的損失（定量化余地） | 突発停止による生産損失、属人的な保全タイミング判断による過剰／過小保全コスト |
| 真の潜在ニーズ | 「特殊性を否定されたくない」のではなく、**「場当たり対応の負債を整理し、本当に特殊な部分とそうでない部分を切り分けたい」「保全判断の負担と責任を一人で背負いたくない」** |

### 営業

| 項目 | 内容 |
|---|---|
| 表面上の悩み | 「お客様ごとに違うから標準化できない」／「AIに提案書を書かせると顧客との関係が薄れる」 |
| 恐怖（Fear） | 顧客との関係性という自分の存在価値の源泉が失われる恐怖／標準化されることで自分の営業成績上の差別化要因が失われる恐怖 |
| 構造的ボトルネック | 見積作成のたびに技術・生産技術への確認が個別・非構造的に発生する／提案書作成が担当者個人の記憶・経験頼みで再現性がない |
| 構造的損失（定量化余地） | 提示までのリードタイム長期化による失注機会損失、確認往復にかかる工数 |
| 真の潜在ニーズ | 「顧客関係を奪われたくない」のではなく、**「非付加価値作業（確認往復・たたき台作成）から解放され、顧客との対話・関係構築に時間を使いたい」** |

## 全部門共通の潜在ニーズパターン

4部門の分析から、部門を問わず共通する構造が見える。

1. **恐怖の正体は「AI」ではなく「評価されないまま代替されること」**: どの部門も、変化そのものより「自分の専門性・判断が正しく評価されないまま置き換えられること」を恐れている。
2. **真の潜在ニーズは「非付加価値作業からの解放」**: 検査基準の言語化、過去判断の検索、保全タイミングの整理、確認往復の解消——いずれも「専門判断」そのものではなく、専門判断の**手前にある定型作業**がボトルネックになっている。

この2点から、教育戦略の設計原則を導く: **AIツールの操作方法を教える研修ではなく、各部門の担当者が「自分の専門性が正しく評価され、非付加価値作業から解放される」体験を、本人の実課題で提供すること**が、真の潜在ニーズに応える唯一の方法である（`02_SOLUTIONS/action_learning_program/` で具体化する）。
