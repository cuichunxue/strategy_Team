# 製造業AI活用戦略チーム プロジェクト環境

製造業社内でAI活用を推進し、業務改革を成功させるための戦略チームのプロジェクト環境。

## 体制

- **推進リーダー**（役員／DX推進部長）: 意思決定者
- **カイゼン（CAO）**: 推進リーダーと1対1で対話するAI最高AI責任者。役割の詳細は [`PROFILE.md`](./PROFILE.md) を参照。

運用ルールの全体像は [`RULES.md`](./RULES.md) を参照。

## ディレクトリ構成

| ディレクトリ | 役割 |
|---|---|
| [`00_GOVERNANCE/`](./00_GOVERNANCE) | セキュリティルール・セキュリティガイドライン |
| [`01_ISSUES/`](./01_ISSUES) | 現場から上がった課題・ニーズの管理シート |
| [`02_PROTOTYPES/`](./02_PROTOTYPES) | 分析コード（Python等）・プロンプト・ツール仕様書 |
| [`SKILLS/`](./SKILLS) | 成功した分析パターン（QCストーリー監査・信頼性解析等）のモジュール |
| [`LOGS/`](./LOGS) | 推進リーダーとカイゼンの対話・意思決定ログ |

## 基本フロー

課題登録（01_ISSUES）→ 評価・検証（02_PROTOTYPES）→ 資産化（SKILLS）→ 全過程を記録（LOGS）、を00_GOVERNANCEのルールの上で回す。詳細は `RULES.md` を参照。
