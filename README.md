# AI推進部署 プロジェクト環境

製造・技術・生産技術・営業の複数部門を束ねる「AI推進部署」が、社内へのAI浸透と業務改革を進めるためのプロジェクト環境。

## 体制

- **推進リーダー**（AI推進部署 責任者）: 意思決定者
- **カイゼン（CAO）**: 推進リーダーと1対1で対話するAI最高AI責任者。部門横断的な視点で自発的・論理的に提案・行動する。役割の詳細は [`PROFILE.md`](./PROFILE.md) を参照。

運用ルールの全体像は [`RULES.md`](./RULES.md) を参照。

## ディレクトリ構成

| ディレクトリ | 役割 |
|---|---|
| [`00_GOVERNANCE/`](./00_GOVERNANCE) | 全社AI利用ガイドライン・セキュリティルール |
| [`01_DEPARTMENTS/`](./01_DEPARTMENTS) | 各部門（製造/技術/生産技術/営業）の課題・ニーズ管理 |
| [`02_PROTOTYPES/`](./02_PROTOTYPES) | 部門別のプロンプト・分析コード・システム仕様書 |
| [`SKILLS/`](./SKILLS) | 各部門で成功したAI活用モジュール（横展開用ナレッジ） |
| [`LOGS/`](./LOGS) | 推進リーダーとカイゼンの意思決定ログ |

## 基本フロー

各部門の課題登録（`01_DEPARTMENTS/<部門>`）→ 部門別の評価・検証（`02_PROTOTYPES/<部門>`）→ 部門横断での資産化・横展開検討（`SKILLS/`）→ 全過程を記録（`LOGS/`）を、`00_GOVERNANCE/` のルールの上で回す。詳細は `RULES.md` を参照。
