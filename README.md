# AIビジョナリー プロジェクト環境

製造業の全社業務改革・利益最大化・第一原理による本質的課題解決を達成するための、マルチエージェント型AIプロジェクト環境。社内AI推進部としての伴走支援ではなく、部門も顧客も気づいていない潜在ニーズを見抜き、戦略として描き切るビジョナリーとして機能することを目的とする。

## 体制

- **改革オーナー**（経営陣／AI推進部署 最高責任者）: 最終意思決定者
- **ジョブズ（AI Chief Visionary Officer）**: 改革オーナーと1対1で対話するAIビジョナリー。第一原理思考でデータ・事実を裏付けとしつつ、部門自身も言語化できていない潜在ニーズを見抜き、自発的・批判的・戦略的に行動する。役割の詳細は [`PROFILE.md`](./PROFILE.md) を参照。

運用ルールの全体像は [`RULES.md`](./RULES.md) を参照。特に冒頭の「ノンネゴシアブル原則」（第一原理主義／定量インパクト必須／安全・品質のノンネゴシアブル／成功パターンの標準化）は最上位の原則。

## ディレクトリ構成

| ディレクトリ | 役割 |
|---|---|
| [`00_STRATEGY/`](./00_STRATEGY) | 全社改革ロードマップ・各部門のROI試算・経営提言書 |
| [`01_DIAGNOSTICS/`](./01_DIAGNOSTICS) | 各部門（製造/技術/生産技術/営業）の第一原理による潜在ニーズ診断・課題管理シート |
| [`02_SOLUTIONS/`](./02_SOLUTIONS) | 改革ソリューション（プロトタイプ仕様書・自動化コード・BPR業務フロー） |
| [`SKILLS/`](./SKILLS) | 成功した改革フレームワーク（QCストーリー監査・信頼性解析モデル・BPR仕様等）の汎用モジュール |
| [`LOGS/`](./LOGS) | 改革オーナーとジョブズの戦略対話ログ |

## 基本フロー（潜在ニーズ起点の第一原理サイクル）

各部門の表面課題登録・潜在ニーズ診断（`01_DIAGNOSTICS/<部門>`）→ 定量インパクト試算（`00_STRATEGY/ROI_LEDGER.md`）→ ソリューション設計・実証（`02_SOLUTIONS/<部門>`）→ 部門横断での資産化・横展開（`SKILLS/`）→ 全過程を記録（`LOGS/`）というサイクルを、`RULES.md` のノンネゴシアブル原則の上で回す。
